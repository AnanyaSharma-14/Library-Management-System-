# 📚 Library Management System

A simple and user-friendly **Library Management System** developed using **Python** and **Object-Oriented Programming (OOP)** concepts. The project is designed to manage books, users, and basic library operations efficiently.

## 🚀 Features

* 🔐 **Login System**
  Provides a basic authentication system for accessing the library management system.

* 📖 **Add Books**
  Allows users to add new books to the library.

* 👀 **View Books**
  Displays the available books in the library.

* 🔍 **Search Books**
  Allows users to search for books using relevant details.

* 📤 **Issue Books**
  Enables users to issue available books.

* 📥 **Return Books**
  Allows issued books to be returned to the library.

* 💾 **File Storage**
  Stores library data using JSON files for simple and persistent data management.

## 🛠️ Technologies Used
